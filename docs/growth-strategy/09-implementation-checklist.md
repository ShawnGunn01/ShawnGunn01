# Implementation Checklist: Week-by-Week Execution Guide

Complete checklist for executing Gunn International's growth strategy system from Day 1 through sustainable operations (Month 3+). Use alongside the 30-Day Roadmap and Growth Operator SOP.

---

## WEEK 1: FOUNDATION & SYSTEM SETUP

### Monday: Planning & Resource Alignment
- [ ] Schedule strategy alignment call with Shawn (30 min)
- [ ] Confirm Growth Operator hire/onboarding start date
- [ ] Identify secondary team support (if needed): content writer, designer, etc.
- [ ] Review 90-Day Growth Strategy doc with full team
- [ ] Confirm: Which 4 sequences launching first? (GROW/TRANSACT/TRANSFORM/CAPITALIZE)
- [ ] Set Day 30 go/no-go criteria in team language
- [ ] Assign DRI (directly responsible individual) for each channel:
  - [ ] Shawn: LinkedIn
  - [ ] Growth Op: Outbound email
  - [ ] Shawn + Growth Op: Referral partners

### Tuesday–Wednesday: HubSpot Configuration
- [ ] Create HubSpot account (if not existing)
- [ ] Set up custom fields:
  - [ ] `trigger_type` (GROW/TRANSACT/TRANSFORM/CAPITALIZE)
  - [ ] `company_revenue`
  - [ ] `account_score` (0–100)
  - [ ] `decision_timeline`
  - [ ] `outreach_status`
  - [ ] `email_performance`
  - [ ] `linkedin_engagement_source`
- [ ] Create pipeline stages: Raw Contact → Sequence Active → Replied → Meeting Booked → Discovery Call → Proposal → Closed Won
- [ ] Test contact import workflow
- [ ] Set up integrations (Apollo → HubSpot sync)
- [ ] Create dashboard view: 90-day pipeline overview
- [ ] Test: Create dummy contact, move through stages

### Thursday: Apollo.io Configuration
- [ ] Create Apollo account
- [ ] Verify company domain (SPF/DKIM)
- [ ] Enable warm-up protocol (Apollo Warmup)
- [ ] Create 4 email sequences (GROW, TRANSACT, TRANSFORM, CAPITALIZE)
- [ ] Test email rendering (Outlook, Gmail, mobile)
- [ ] Set email timing defaults (11am send time)
- [ ] Enable open/reply tracking
- [ ] Configure HubSpot integration
- [ ] Test: Send 1 email to yourself, confirm tracking works
- [ ] Monitor sender reputation score (should be 80+)

### Friday: LinkedIn & Calendly Setup
- [ ] Refresh Shawn's LinkedIn profile:
  - [ ] Update headline (emphasize expertise/decision categories)
  - [ ] Strengthen summary (2–3 brief case studies)
  - [ ] Add recent media/content links
  - [ ] Enable "Open to advising" on profile
- [ ] Activate LinkedIn Sales Navigator (if not active)
- [ ] Install Taplio (or native scheduling tool)
- [ ] Set up Calendly account:
  - [ ] Create event type: "Strategy Call" (30 min, available Tue/Wed/Thu 1–5pm)
  - [ ] Set up timezone handling
  - [ ] Add to email signature
- [ ] Create 50-person strategic relationship list in Google Sheets:
  - [ ] Name, title, company, LinkedIn URL, relationship type (Tier A/B/C)

### Friday EOD: Week 1 Checkpoint
- [ ] HubSpot live with custom fields + pipeline
- [ ] Apollo live with sequences configured
- [ ] LinkedIn profile updated
- [ ] Calendly live and linked
- [ ] Growth Operator onboarding materials ready
- [ ] All team members have access to tools
- [ ] Schedule Week 2 kickoff call

**Owner**: Shawn (coordination) + Growth Op (tool configuration)  
**Success Metric**: All systems tested and operational  
**Blocker Check**: Any access issues? Any missing integrations? Resolve before proceeding

## WEEK 2: CONTENT PREP & ACCOUNT RESEARCH

### Monday–Tuesday: LinkedIn Content Preparation
- [ ] Outline 12 posts for Month 1 (3 per pillar: GROW/TRANSACT/TRANSFORM/CAPITALIZE)
  - [ ] 4 flagship "Decision" posts (1 per pillar)
  - [ ] 4 "Contrarian Note" posts (1 per pillar)
  - [ ] 4 "The Read" posts (curated content)
- [ ] Draft messaging angles for each post
- [ ] Create graphics/images for flagship posts (or identify stock images)
- [ ] Schedule in Taplio for Weeks 2–4
- [ ] Confirm: Are 2 posts/week achievable for Shawn? Adjust schedule if needed

### Wednesday: Account Research & Targeting
- [ ] Identify 200–300 target accounts via:
  - [ ] Apollo (revenue $10M–$100M filter)
  - [ ] Crunchbase (recent funding filter)
  - [ ] LinkedIn Sales Navigator (keyword + industry search)
- [ ] For each account, document:
  - [ ] Company name, revenue, sector, recent funding/news
  - [ ] CEO/Founder name, title
  - [ ] VP Revenue name, title (for GROW sequence)
  - [ ] CFO name, title (for TRANSACT/CAPITALIZE)
- [ ] Upload to Apollo (bulk import)
- [ ] Let Apollo auto-enrich contact data

### Thursday: Target Account Scoring
- [ ] Score all 200–300 accounts on 0–100 model (see ABM Operating System doc)
- [ ] Segment into Priority tiers:
  - [ ] Priority 1 (80–100): Email in Weeks 2–3
  - [ ] Priority 2 (60–79): Email in Weeks 3–4
  - [ ] Priority 3 (40–59): Email in Weeks 4+
- [ ] Focus intensively on Priority 1 (40–50 accounts minimum)
- [ ] Export scored list to HubSpot

### Friday: Email Sequence Customization
- [ ] Review 4 email templates (GROW, TRANSACT, TRANSFORM, CAPITALIZE)
- [ ] Customize for Shawn's voice:
  - [ ] [ ] Adjust tone/examples to match Shawn's style
  - [ ] [ ] Ensure 2+ personalization zones in each email
  - [ ] [ ] Confirm subject line formula fits brand
- [ ] Create role-specific variations:
  - [ ] [ ] CEO angle version
  - [ ] [ ] CFO angle version
  - [ ] [ ] VP Revenue angle version
  - [ ] [ ] Board Chair angle version
- [ ] Test rendering in Apollo
- [ ] Upload to Apollo sequences

### Friday EOD: Week 2 Checkpoint
- [ ] 200–300 target accounts identified and uploaded to Apollo
- [ ] All accounts scored 0–100
- [ ] Priority 1 accounts (40–50) ready for immediate outreach
- [ ] 12 LinkedIn posts drafted and scheduled
- [ ] 4 email sequences customized and tested
- [ ] Growth Operator trained on research template
- [ ] First 20 emails personalized and ready to deploy Week 3

**Owner**: Shawn (content), Growth Op (account research + scoring)  
**Success Metric**: Ready to launch Week 3  
**Blocker Check**: Do we have high-quality account list? Is email quality high? Adjust before proceeding

### Friday EOD: Week 3 Checkpoint

## Quality Gates (All Phases)

**Do not proceed without**:
- ✅ Every email has 2+ personalization zones
- ✅ Every email <150 words
- ✅ Every email has specific CTA (not generic)
- ✅ Account score ≥40 or clear new trigger
- ✅ LinkedIn posts decision-category specific
- ✅ Subject line <60 characters, specific
- ✅ Reply escalation to Shawn <1 hour for warm leads

**If quality slips**:
- Pause and audit (don't continue at reduced quality)
- Identify root cause
- Adjust volume if needed
- Retrain Growth Op on standards

---

## Escalation Points

**Growth Op escalates to Shawn immediately if**:
- Email open rate drops <18% for 3+ days
- LinkedIn engagement <2% for 2+ weeks
- Sudden spike in bounces (>5% daily)
- No calls booked by Week 4
- Negative feedback from prospects on messaging
- Referral partner interest weak (<4 committed by end Month 1)

**Shawn escalates to Growth Op if**:
- Calls converting at <20% (possible qualification issue)
- Repetitive "not a fit" feedback (possible ICP drift)
- Too many low-quality leads (research quality issue)
